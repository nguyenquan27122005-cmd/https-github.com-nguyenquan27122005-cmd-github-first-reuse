# Example: Financial Statement Analysis

User request: build a financial-statement analysis application.

Decompose and search separately for:
- PDF/Excel/XBRL ingestion
- table extraction
- statement normalization/taxonomy mapping
- ratio and DuPont engines
- cash-flow quality
- valuation/peer comparison
- annual-report RAG/commentary
- dashboard/report generation

Prefer a composed architecture when focused components are stronger than a monolithic repository.

Before reuse, verify code, license, dependencies, maintenance status, tests, and integration fit.
